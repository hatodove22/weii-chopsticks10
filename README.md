# (☝ ՞ਊ ՞)☝ｳｪｰｲ ←このゲーム

スマホのブラウザで遊ぶ、チョップスティックスのタイムアタック。

- AI1体を10秒以内に撃破。
- 10体すべてを合計100秒以内に撃破。
- 左右1本ずつから開始。自分の手、相手の手の順にタップして本数を加算。
- 5本以上になった手は脱落。両手脱落、または時間切れでゲームオーバー。
- 指の分け直し・復活なし。プレイヤーは後攻。
- 自己ベストをブラウザ内に保存。

プレイ: https://hatodove22.github.io/weii-chopsticks10/
